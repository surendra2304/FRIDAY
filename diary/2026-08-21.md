## Session 2 — Text/Reasoning Provider Independence: Groq, Cerebras, OpenRouter & Fallback Chain

I added `GroqLLMProvider`, `CerebrasLLMProvider`, and `OpenRouterLLMProvider` — all using the OpenAI Python SDK against each platform's OpenAI-compatible endpoint. I built `FallbackChainLLMProvider` that tries providers in order (Groq -> Cerebras -> OpenRouter), advancing on any `LLMProviderError`. I activated it via `FRIDAY_LLM_PROVIDER=chain`. Groq gets an internal 429 model-fallback to `llama-3.1-8b-instant` before escalating. I added a non-singleton `OpenAICompatibleCredentialPool` with three independent pools and separate health state files. I extended `Settings` with all new provider fields and updated `llm/factory.py` to support 8 providers total. Voice/vision isolation is total: Groq/Cerebras/OpenRouter never touch the Gemini pool.

**Bug Fixed:** Bug #28 — `time.sleep` global patch contamination where background Win32 threads from hardware tests leaked into the mock and tripped `assert_not_called()`. Fixed by filtering for retry-scale sleeps (>= 1.0s).

**Verification:** 897 passed, 9 deselected — including 46 new mock tests for all 3 providers and the fallback chain.
