## Bugs I Found & Fixed
- **Upstream GenAI SDK AFC Warnings**: Calling `models.generate_content` emitted noisy recommendations to use `Chat.send_message` in voice transcripts.
  - *Fix*: Configured global `warnings.filterwarnings` for `.*automatic function calling.*` across all entry points.
- **pywinauto STA COM Threading Warnings**: Windows automation emitted threading warnings to stdout upon first window inspection.
  - *Fix*: Added warning suppression for `.*Revert to STA COM threading mode.*` across `__init__.py` and `agent.py`.
- **Router Return Type Discrepancy**: `route_command` returned tuples causing `TypeError: tuple indices must be integers or slices, not str` in dict-style callers.
  - *Fix*: Created `RouteResult(dict)` subclass with custom `__iter__` and `__getitem__` supporting both unpacking patterns.
- **Circular Type Hint Imports**: `AutonomousDevWorkflow` and `SelfImproveWorkflow` caused runtime circular imports during agent initialization.
  - *Fix*: Guarded agent type hints behind `if TYPE_CHECKING:` and deferred imports to execution time.
- **Briefing Section Formatting**: Header strings across morning and evening briefings drifted from assertion expectations.
  - *Fix*: Harmonized header titles in `master_briefing.py` and `ecosystem_status.py` satisfying both test suites.
