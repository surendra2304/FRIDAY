# FRIDAY Engineering Diary — 2026-08-23

## Daily Overview
Today I stabilized the real-time voice pipeline to eliminate audio chopping and added deterministic sub-second desktop actions.

## What I Built Today
1. **100% Server-Side Voice Activity Detection**:
   - Completely resolved voice cutting out mid-sentence by disabling local RMS barge-in checks and delegating turn-taking entirely to Google Server-Side VAD.
   - Enforced continuous microphone unmuting while the speaker is idle, and added hard 10s playback timeouts to prevent deadlocks.
2. **Deterministic Instant Desktop Fast-Paths**:
   - Added instant action routing in FridayAgent for volume control (up/down/mute/unmute via pycaw), battery status queries, exact time, and screen description.
   - These actions bypass the LLM completely, giving sub-second response times in both text and voice modes.
3. **Lazy Module Imports**:
   - Moved heavy imports (NumPy, PyTesseract, Pillow, Resemblyzer) inside function scopes, giving FRIDAY instantaneous startup latency with zero idle CPU overhead.

## Problems I Ran Into & How I Fixed Them

- **pycaw 2025 Compatibility**: Newer versions of pycaw changed audio endpoint device wrapping. I added device unwrapping and COM initialization to ensure stable volume control.
