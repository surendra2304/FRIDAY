## Bugs I Found & Fixed
- **Memory Compaction SQLite Locks**: Concurrent memory compaction blocked read operations.
  - *Fix*: Wrapped memory compactor writes in dedicated transaction locks with WAL mode.
- **Background Scheduler Auth Bypass**: Background jobs attempted tool execution without tokens.
  - *Fix*: Bound all scheduled jobs to valid DefaultSecureAuthorizer capability tokens.
- **Window Typing Focus Settle**: Fast keystroke dispatch dropped initial characters.
  - *Fix*: Added 0.5s SetForegroundWindow settle delay before dispatching keystrokes.
- **Calendar Timezone Offset**: Recurring .ics events parsed with UTC drift.
  - *Fix*: Normalized timezone offsets to local machine timezone during ical parsing.
