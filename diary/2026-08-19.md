# FRIDAY Engineering Diary — 2026-08-19

## Daily Overview
Today I focused on modernizing FRIDAY with Google's official `google-genai` SDK and implementing a true full-duplex live voice conversational pipeline over WebSockets.

## What I Built Today
1. **Full-Duplex Live Voice Streaming**:
   - I deprecated the old turn-based voice prototype and built real-time bidirectional WebSocket streaming using `client.aio.live.connect`.
   - Created `MicrophoneStream` capturing 16kHz PCM audio and `SpeakerStream` playing 24kHz audio smoothly.
   - Built dual-layer barge-in: local audio energy detection paired with server-side voice activity detection for seamless interruption.
2. **Multi-Key Credential Pool**:
   - Implemented `GeminiCredentialPool` to dynamically manage multiple API keys with persistent health tracking.
   - Added automated key rotation during rate limits (HTTP 429) to keep conversations alive without crashing.
3. **Terminal Polish & Persona**:
   - Tuned system prompts to give FRIDAY a calm, concise, and helpful conversational tone.
   - Directed `DEBUG` and `INFO` logs to disk files, keeping the main terminal clean and uncluttered.

## Problems I Ran Into & How I Fixed Them
- **Live Reconnect Parameter Crash**: The connection was crashing with an error about `transparent` parameters. I tracked down the issue in `SessionResumptionConfig` and removed the incompatible flag.
- **Quota Leaks in Tests**: Unit tests were occasionally making real network requests. I wrote an isolation fixture in `conftest.py` ensuring all unit tests run 100% offline.
- **Console Log Spam**: Internal debug chatter was polluting the terminal. I decoupled the console log level to `WARNING` while keeping full debug traces in log files.

## Testing & Verification
- I verified live audio hardware on my laptop: microphone input and speaker playback passed cleanly.
- Full test suite grew to 264 automated tests, all passing with zero errors.
