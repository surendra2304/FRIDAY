## Bugs I Found & Fixed

### Bug #05
- **Symptoms**: Gemini Live Reconnect Crash (failed with `"transparent parameter is only supported in Gemini Enterprise Agent Platform mode"`).
- **Root Cause**: `SessionResumptionConfig` had `transparent=True` hardcoded.
- **Fix**: I removed `transparent=True` from `SessionResumptionConfig` in `gemini_live_session.py`.
- **Verification**: Live Reconnect PASS.

### Bug #06
- **Symptoms**: Fallback Keys Missing from Disk.
- **Root Cause**: The script had not flushed environment variables to the physical `.env` file.
- **Fix**: I populated all 4 fallback keys in `.env` and executed real failover verification.
- **Verification**: Real Fallback Failover PASS.

### Bug #07
- **Symptoms**: Model 404 for New Projects for `gemini-2.5-flash`.
- **Root Cause**: Google deprecated `gemini-2.5-flash` for new developer API accounts.
- **Fix**: I updated the default text model in `config.py` to `gemini-3.6-flash`.
- **Verification**: Automated tests pass.

### Bug #08
- **Symptoms**: Console Log Spam.
- **Root Cause**: Console logger was attached at `DEBUG`/`INFO` level.
- **Fix**: I updated `setup_logging` to support a separate `console_level=logging.WARNING`.
- **Verification**: Terminal UX PASS.

### Bug #09
- **Symptoms**: Slow Offline Pytest (tests leaked into real network calls).
- **Root Cause**: Missing autouse isolation fixture in `conftest.py`.
- **Fix**: I added `isolate_test_environment` in `conftest.py`.
- **Verification**: Tests run 100% offline.
