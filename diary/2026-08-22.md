Addressed (`hello FRIDAY`) and compound requests (`hey, open notepad`) intentionally fall through to the normal pipeline; the LLM handles conversational greetings via the system-prompt GREETING HANDLING rule.

- **Bug #29 (Text Provider Silently Gemini in Live Runs)**: `.env` still had `FRIDAY_LLM_PROVIDER=gemini`, so the live agent never used the new chain despite the factory supporting it. - **Bug #30 (pywinauto Launch Fails for Browsers)**: `Application().start("chrome.exe")` raises because browsers are registered under App Paths, not PATH. Replaced with `os.startfile` + `subprocess.Popen` fallback; protocol URIs (`ms-settings:`) also supported.
- **Bug #31 (Greetings Triggered Clarification Loop)**: the prompt-level GREETING HANDLING rule was insufficient because the cognitive engine intercepted greetings and asked for clarification before the LLM saw them. Added a hardcoded greeting fast-path in `process_message()` before the cognitive evaluation.
