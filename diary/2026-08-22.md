- Added the greeting fast-path to `FridayAgent.process_message()`: bare greetings (`hi`, `hello`, `hey`, `sup`, optionally "there" + punctuation) return a random conversational response directly — recorded in memory with proper state-machine transitions — completely bypassing the cognitive loop (which previously asked for clarification), capability routing, and tool calling. Addressed (`hello FRIDAY`) and compound requests (`hey, open notepad`) intentionally fall through to the normal pipeline; the LLM handles conversational greetings via the system-prompt GREETING HANDLING rule.
- Test hygiene: `test_default_settings` now asserts the `llm_provider` *field default* from the model schema (a local `.env` may legitimately override the constructed value); `test_agent_user_friendly_exceptions` uses a non-greeting input so the connection-error path is actually exercised.
