## Bugs / Errors Discovered
### Bug #01
- Symptoms: `UnicodeEncodeError` on `cp1252` terminal during banner rendering.
- Root Cause: Windows PowerShell defaults to `cp1252` codepage which cannot encode unicode block characters.
- Fix: Replaced banner with pure ASCII block art and added `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`.
- Verification: Tests pass.

### Bug #02
- Symptoms: Logging Traceback Leakage.
- Root Cause: Standard Python `logging.Filter` only inspects `LogRecord.msg`, not formatted tracebacks.
- Fix: Implemented `SanitizedFormatter` intercepting final formatted string outputs.
- Verification: Tests pass.

### Bug #03
- Symptoms: JSON Serialization in Tool Calls produced invalid single-quoted JSON strings.
- Root Cause: `Message.to_provider_dict()` invoked `str(arguments)` instead of `json.dumps(arguments)`.
- Fix: Replaced argument serialization with `json.dumps()`.
- Verification: Tests pass.

### Bug #04
- Symptoms: Path Traversal Vulnerability.
- Root Cause: Lack of absolute path checks before `Path.resolve()`.
- Fix: Hardened `FileReaderTool` and `FileListingTool` to reject absolute/drive-anchored paths and verify workspace containment.
- Verification: Tests pass.
