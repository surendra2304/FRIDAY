## Bugs I Found & Fixed
- **Bug #01 (cp1252 Terminal Encoding)**: UnicodeEncodeError during banner rendering on Windows PowerShell.
  - *Root Cause*: Windows PowerShell defaults to cp1252 codepage which cannot encode unicode block characters.
  - *Fix*: I replaced the banner with pure ASCII block art and added sys.stdout.reconfigure(encoding="utf-8").
  - *Verification*: Verified banner rendering in Windows PowerShell and cmd.exe.
- **Bug #02 (Traceback Leakage)**: Standard logging filter missed formatted tracebacks in log records.
  - *Root Cause*: Standard Python logging.Filter only inspects LogRecord.msg, not formatted tracebacks.
  - *Fix*: I implemented SanitizedFormatter intercepting final formatted string outputs.
  - *Verification*: Verified zero secret or traceback leakage across console and file logs.
- **Bug #03 (JSON Serialization)**: Tool arguments used single-quoted repr strings causing JSON decode errors.
  - *Root Cause*: Message.to_provider_dict() invoked str(arguments) instead of json.dumps(arguments).
  - *Fix*: I replaced argument serialization with json.dumps().
  - *Verification*: Verified valid JSON format in all outgoing tool call payloads.
- **Bug #04 (Path Traversal)**: File tools accepted absolute paths outside workspace.
  - *Root Cause*: Lack of absolute path checks before Path.resolve().
  - *Fix*: I hardened FileReaderTool and FileListingTool to reject drive-anchored paths outside workspace.
  - *Verification*: Verified path traversal rejection unit tests pass.
