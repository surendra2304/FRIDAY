## Bugs I Found & Fixed
- **Bug #10 (Acoustic Echo Leakage)**: Low-ambient RMS threshold caused false barge-in during speaker speech.
  - *Root Cause*: Acoustic feedback from physical speakers re-entered the laptop microphone.
  - *Fix*: Raised RMS threshold and added speaker-active muting logic in audio pipeline.
  - *Verification*: Verified speaker audio does not trigger false interruptions.
- **Bug #11 (ctypes Screen Capture Overflow)**: Missing 64-bit argtypes caused buffer calculation overflow.
  - *Root Cause*: 32-bit default return types truncated memory addresses on 64-bit Windows.
  - *Fix*: Explicitly defined ctypes argtypes and restypes for all Win32 GDI functions.
  - *Verification*: Verified full-resolution 1536x864 screen capture works without crashes.
- **Bug #12 (Vision Quota Exhaustion)**: Static screens repeatedly drained cloud API quota.
  - *Root Cause*: Unconditional screen uploads occurred on every turn even when UI was unchanged.
  - *Fix*: Added SHA-256 image byte hash cache with 30-second TTL to skip identical frames.
  - *Verification*: Verified static screen queries bypass cloud vision model calls.
- **Bug #13 (Tool False Success)**: Tools reported execution success without verifying actual outcome.
  - *Root Cause*: Tool returned True based solely on subprocess exit code 0.
  - *Fix*: Built StepVerifier to inspect filesystem, process table, and screen state before confirming.
  - *Verification*: Verified false-positive tool executions are caught and rejected.
