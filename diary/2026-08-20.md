## Bugs / Errors Discovered
### Bug #10
- Symptoms: Ambient microphone input in quiet environments produced low RMS energy.
- Root Cause: System had 17 audio input/output endpoints. Default input selection required explicit device pinning support.
- Fix: Added device selection configuration fields in Settings.
- Verification: Microphone Non-Silent Audio PASS.

### Bug #11
- Symptoms: Terminal logs were saturated with rapid `session_resumption_update` events.
- Root Cause: `session_resumption_update` emitted continuously by Gemini Live.
- Fix: Throttled session resumption debug logging to only log when the resumption handle token changes.
- Verification: Terminal UX PASS.

### Bug #12
- Symptoms: Acoustic leakage from laptop speakers into the microphone triggered immediate local barge-in.
- Root Cause: `_audio_sender_loop` previously checked single-frame RMS without duration debounce, speaker echo scaling, or cooldown.
- Fix: Added debounce window, speaker echo multiplier, cooldown window.
- Verification: False Barge-In Echo Suppression PASS.

### Bug #13
- Symptoms: Large acoustic echo spikes (RMS > 7000) from physical laptop speakers broke single-threshold checks.
- Root Cause: Unfiltered local RMS detector competed with Gemini Live's server-side neural VAD.
- Fix: Implemented hierarchical VAD architecture; Gemini Server VAD is primary for room speaker playback; adaptive ambient noise floor EMA tracking.
- Verification: Speaker Mode Self-Interruption PASS.

### Bug #14
- Symptoms: `GeminiLiveVoiceSession.__init__` defaulted `vad_start_sensitivity` to `"HIGH"`, overriding the intended `config.py` default `"LOW"`.
- Root Cause: Redundant fallback in constructor constructor signature (`getattr(settings, "voice_vad_start_sensitivity", "HIGH")`).
- Fix: Updated default in `GeminiLiveVoiceSession.__init__` to match `config.py` (`"LOW"`, `prefix_padding_ms=300`, `silence_duration_ms=800`). Added safe telemetry instrumentation.
- Verification: 275/275 automated tests passing.

### Bug #15
- Symptoms: CLI ASCII banner letters were excessively spaced apart, appearing as disconnected fragments with an overly wide 'A' geometry and ragged right margin.
- Root Cause: Individual letter blocks in `FRIDAY_LOGO_LINES` had mismatched column widths and up to 8-space gaps.
- Fix: Rebuilt `FRIDAY_LOGO_LINES` into a unified 41-char cohesive block wordmark with 1-column spacing, uniform 6-row height, matching baselines, and whole-word centering.
- Verification: Visual PowerShell inspection and automated CLI test pass.
