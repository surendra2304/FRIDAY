## Bugs I Found & Fixed
- **UptimeRobot 405 Method Not Allowed**: Health probes sent HTTP HEAD requests which failed on default GET-only FastAPI routers.
  - *Fix*: Added explicit `HEAD` route handlers to `/` and `/health` across Cortex, Futuris, Inference, IntelX, and Memora.
- **Docker Container Dynamic PORT Binding**: Render assigns random `$PORT` environment variables causing containers bound to static ports to fail health checks.
  - *Fix*: Updated Dockerfiles to parse `$PORT` dynamically with fallback defaults.
- **Turso Cloud DB Directory Creation**: SQLite fallback failed when parent `data/` directory was missing on container cold starts.
  - *Fix*: Added auto-creation of missing data directories before opening connection pools.
