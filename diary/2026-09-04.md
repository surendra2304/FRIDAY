## Bugs I Found & Fixed
- **Event Loop Deadlock in Tool Execution**: Calling `asyncio.run()` inside an active loop caused nested event loop crashes.
  - *Fix*: Integrated `_run_coroutine_safely()` utilizing a decoupled `ThreadPoolExecutor` worker thread when called from a running loop.
- **Base64 False Positives in Prompt Injection Guard**: Overbroad regex matched benign discussion of base64 encoding.
  - *Fix*: Restructured regex to strictly match execution contexts (`(?is)(?:decode|execute|run|paste|eval).*?\bbase64\b`).
- **Specialist Agent False Successes**: `BaseAgent` reported `success=True` even when sub-tasks failed with tool errors.
  - *Fix*: Enforced strict failure attribution when any tool execution reports `is_error=True`.

## Key Decisions & Architecture
- Untrusted Ingress Separation: All external web, OCR, and tool data is treated strictly as passive data, never control instructions.
- Strict Sandboxing: Disallowed absolute paths and directory traversal in local file inspection tools.
- Idempotency Deduplication: Enforced action fingerprint locking across parallel worker threads.
