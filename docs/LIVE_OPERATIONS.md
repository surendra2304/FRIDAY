## 🎙️ Voice Command Reference & Authorization Tiers

### 1. SAFE Commands (Instant Execution — No Auth Required)
| Natural Language Command | Triggered Subsystem | Spoken / Output Response |
| :--- | :--- | :--- |
| `"What's my live P&L?"` | `LiveOperationsCenter` | Realized, unrealized, and cumulative today P&L. |
| `"How far from my risk limits?"` | `LiveOperationsCenter` | Remaining daily loss headroom ($) and drawdown used (%). |
| `"What are my live positions?"` | `LiveOperationsCenter` | Detailed list of active symbols, sides, sizes, entries, and unrealized gains. |
| `"What capital level am I on?"` | `CapitalLevelGuardian` | Current tier, capital ceiling, clean days count, and progression eligibility. |
| `"Live trading status"` | `LiveOperationsCenter` | Operating mode (`LIVE`), equity, effective leverage, and proximity status. |
| `"Daily trading report"` | `LivePerformanceAnalytics`| Rolling 30d return %, Sharpe ratio, top strategy, and AI alpha impact. |

### 2. SENSITIVE Commands (Requires Voice Biometrics $\ge 0.85$)
| Natural Language Command | Action Executed | Safety Effect |
| :--- | :--- | :--- |
| `"Emergency flatten all positions"` | `EmergencyProcedureManager.trading_halt()` | Halts trading engine and requests complete market liquidation. |
| `"Halt live trading"` | `TradingBotOperator.toggle_advisory(False)` | Disables new trade entries; open positions remain bracketed. |
| `"Resume live trading"` | `TradingBotOperator.toggle_advisory(True)` | Resumes strategy execution and parameter overlay application. |

### 3. DANGEROUS Commands (Requires Biometrics $> 0.95$ + Verbal Confirmation Phrase)
| Natural Language Command | Confirmation Phrase | Action Executed |
| :--- | :--- | :--- |
| `"Activate live trading kill switch"` | `"Confirm emergency action"` | Authoritative `/api/panic` call; permanently stops bot and cancels orders. |
| `"Confirm capital level upgrade"` | `"Confirm capital level upgrade"` | Authorizes capital ceiling expansion in `CapitalLevelGuardian`. |

## 🛡️ Capital Level Progression Guardian

| Capital Level | Tier Name | Max Capital Ceiling | Max Leverage | Max Risk / Trade | Clean Days Required |
| :---: | :--- | :---: | :---: | :---: | :---: |
| **Level 1** | Starter Capital | $5,000 USDT | 2.0x | 1.0% | 0 Days |
| **Level 2** | Growth Capital | $25,000 USDT | 3.0x | 1.5% | 30 Days |
| **Level 3** | Scale Capital | $100,000 USDT | 5.0x | 2.0% | 60 Days |

### Progression Eligibility Criteria:
1. $\ge 30$ consecutive clean days with 0 daily loss or drawdown limit breaches.
2. Cumulative net P&L $> 0$ USDT at current level.
3. 0 active Level 1 or Level 2 critical incidents.
4. Cryptographically signed `CAPITAL_LEVEL_UPGRADE` authorization file generated by FRIDAY and verified by the operator.

## 🚨 Incident Management & Automated Containment Matrix

| Severity | Incident Description | Automated Containment Policy | Voice Alert Urgency |
| :---: | :--- | :--- | :---: |
| **Level 1** | Catastrophic limit breach (Drawdown $>5\%$, anomalous orders) | Emergency Kill Switch (`POST /api/panic`) + Emergency Contact Broadcast | 🚨 CRITICAL (Max Voice) |
| **Level 2** | Daily loss limit reached ($100\%$), Reconciliation mismatch | Immediate Trading Halt (`POST /api/halt`) | 🚨 CRITICAL |
| **Level 3** | AI advisory rejection streak ($>5$), REST API timeout $>30\text{s}$ | Automatic Parameter Rollback (`POST /rollback`) | ⚠️ WARNING |
| **Level 4** | Single position loss $>3\%$, Volatility surge | Throttle position sizing / Leverage capped at 2.0x | ⚠️ WARNING |
| **Level 5** | Operational mode changes, benign alert clearings | Informational logging in audit trail | ℹ️ INFO |

## 📅 Daily Live Operations Schedule

1. **08:00 UTC (Morning Live Briefing)**:
   - Query: *"Live morning briefing"* or *"What's my live P&L?"*.
   - Review overnight fills, risk headroom, and market regime posture.
2. **14:00 UTC (Midday Risk Audit)**:
   - Query: *"How far from my risk limits?"*.
   - Ensure effective leverage $< 2.0\text{x}$ and drawdown $< 2.0\%$.
3. **22:00 UTC (Daily Close & Post-Incident Review)**:
   - Query: *"Daily trading report"*.
   - Verify clean-day counter increment in `CapitalLevelGuardian`.
