# Voice Architecture Design for FRIDAY

## Overview
FRIDAY will gain a **cloud‑first voice subsystem** that enables natural spoken interaction while keeping all heavy speech processing (ASR, TTS, streaming) in Google Gemini services. The design introduces four core abstractions that are completely decoupled from the existing `FridayAgent` implementation:

1. **`VoiceInput`** – Represents a raw audio source (microphone, audio file, or streamed PCM) and provides a coroutine to feed audio chunks to a provider.
2. **`VoiceOutput`** – Consumes text generated by the agent and streams synthesized audio back to a speaker or audio sink.
3. **`VoiceSession`** – Orchestrates a single conversational turn: it wires together a `VoiceInput`, a `VoiceProvider`, the `FridayAgent`, and a `VoiceOutput`. It is responsible for:
   * Capturing the user's spoken utterance.
   * Converting audio → text via the provider.
   * Invoking the existing agent pipeline (including tool safety, memory, etc.).
   * Converting the agent's textual response → audio.
   * Handling mode‑specific flow (push‑to‑talk vs. continuous).
4. **`VoiceProvider`** – An abstract interface that implements two operations:
   * `asr(audio_stream) -> str` – Speech‑to‑text.
   * `tts(text) -> async Iterable[bytes]` – Text‑to‑speech streaming.
   The first concrete implementation will be `GeminiVoiceProvider` which calls the **Gemini Live API** for real‑time ASR and the **Gemini Text‑to‑Speech** endpoint for synthesis. The interface is deliberately provider‑agnostic so future cloud providers (e.g., Azure Speech, AWS Polly) can be swapped without touching the agent core.

## Integration Points
- **No direct microphone/speaker calls inside `FridayAgent`.** The agent continues to accept `Message` objects as before. `VoiceSession` translates the spoken utterance into a `Message(role=Role.USER, content=transcript)` and feeds the agent’s `process_message` method.
- **Safety & Authorization** remain identical because the textual transcript is treated as ordinary user input. No bypass of the existing tool‑level safety checks occurs.
- **Cost‑Mode awareness** is enforced inside `GeminiVoiceProvider`. When `Settings.cost_mode == "free_first"` the provider will prefer the free‑tier streaming endpoints and raise a clear error if a paid tier is required.

## Supported Interaction Modes
| Mode | Description | Implementation Notes |
|------|-------------|----------------------|
| **Text‑only** | Current UI – unchanged. | No changes required. |
| **Push‑to‑Talk** | User presses a key (or CLI command) to start recording, releases to stop, then the voice pipeline runs once. | `VoiceSession.start_push_to_talk()` will open the microphone, capture until the stop signal, then run the full flow. |
| **Continuous (future)** | Ongoing listening with turn‑taking detection. | Design placeholder `VoiceSession.start_continuous()` – currently **not implemented**. |

```python
class GeminiVoiceProvider(VoiceProvider):
    def __init__(self, api_key: str, model: str = "gemini-1.5-flash"):
        self.api_key = api_key
        self.model = model
        # HTTPX client with timeout/retry from Settings

    async def asr(self, audio):
        # Connect to Gemini Live API (streaming) and return transcript
        ...

    async def tts(self, text):
        # Call Gemini TTS endpoint, yield MP3/OGG chunks
        ...
```

```python
class VoiceSession:
    def __init__(self, provider: VoiceProvider, agent: FridayAgent, output_sink: Callable[[bytes], None]):
        self.provider = provider
        self.agent = agent
        self.output_sink = output_sink

    async def run_push_to_talk(self, audio_source: AsyncIterable[bytes]):
        # 1. Speech‑to‑text
        transcript = await self.provider.asr(audio_source)
        # 2. Agent processing (unchanged API)
        response = await self.agent.process_message(Message(Role.USER, transcript))
        # 3. Text‑to‑speech streaming
        async for chunk in self.provider.tts(response.content):
            self.output_sink(chunk)
```

## Test Strategy (CI‑friendly, no hardware)
1. **MockVoiceProvider** – implements `asr` returning a predefined string and `tts` yielding a small in‑memory byte sequence. Used in unit tests for `VoiceSession`.
2. **Integration test** – `tests/test_voice_session.py` will:
   * Instantiate `VoiceSession` with `MockVoiceProvider` and a `FridayAgent` configured with the mock LLM provider.
   * Feed a fake audio generator (e.g., `async def dummy_audio(): yield b""`).
   * Assert that the agent receives the expected transcript and that the output sink receives the expected TTS bytes.
3. **Safety checks** – Verify that a malicious transcript that attempts to trigger a `DANGEROUS` tool still goes through normal authorization flow.
4. **Cost‑mode enforcement** – Ensure `GeminiVoiceProvider` raises `CostModeError` when the configuration requests a paid model while `FRIDAY_COST_MODE=free_first`.
