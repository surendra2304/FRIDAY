## 🛡️ The 6 Mandatory Validation Gates

| Gate ID | Gate Name | Required Acceptance Criteria |
| :---: | :--- | :--- |
| **`GATE_01`** | **Parameter Stability** | Out-of-sample parameter sensitivity variance $\le 15.0\%$. |
| **`GATE_02`** | **Fee & Slippage Drag** | Positive expectancy under simulated $2.5\text{ bps}$ taker fee drag. |
| **`GATE_03`** | **Regime Compatibility** | Multi-timeframe trend/ranging consensus score $\ge 60.0\%$. |
| **`GATE_04`** | **Max Drawdown Ceiling** | Historical 2-year maximum drawdown $\le 5.0\%$. |
| **`GATE_05`** | **Monte Carlo Tail Risk** | 10,000-path simulation 99% VaR $\le 3.0\%$ of allocated capital. |
| **`GATE_06`** | **Risk-Adjusted Alpha** | 2-year historical Sharpe ratio $\ge 1.50$ and Profit Factor $\ge 1.40$. |

## 🧠 Institutional Learning & Failure Pattern Post-Mortems

- **Regime Shift Vulnerability (60%)**: Pure moving average crossovers failed during extended ranging markets. All new strategies now require multi-timeframe regime filters.
- **Slippage Sensitivity (20%)**: Ultra-low timeframes ($<5\text{m}$) suffered excessive fee drag. All new scalping models require limit maker execution.
- **Alpha Decay (20%)**: Standard oscillators decayed as market efficiency increased. Modern candidates incorporate order book imbalance (CVD) and basis yields.
